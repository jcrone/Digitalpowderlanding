# digitalpowder.io

Company landing page for Digital Powder — makers of **MySkiSwap** and **ConsignGear**.

It's a single static page (`index.html` + `favicon.svg`) with no build step. Open `index.html` in a browser to preview, or host it on any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages).

## Before launch

- Confirm the MySkiSwap URL (currently `https://myskiswap.com`).
- Confirm the contact email (currently `hello@digitalpowder.io`).
- The ConsignGear waitlist form uses `mailto:`. For a real signup list, point the form `action` at a form service (Formspree, Netlify Forms, etc.).
- Review the About section copy so it matches your story.
